# FuzzButt
A collection of FizzBuzz implementations

## What is FizzBuzz?
According to [wikipedia](https://en.wikipedia.org/wiki/Fizz_buzz) Fizz Buzz is a word game in which Numbers are counted up incrementally, but replaced with the words "Fizz", "Buzz", or "Fizzbuzz" if the number meets the following division rules:
1. Any number divisible by 3 is replaced with "fizz"
2. Any number divisible by 5 is replaced with "buzz"
3. Any number divisible by both is replaced with "fizzbuzz"

This word game is often used as a programming exercise in classrooms or interviews. Some implementations may leave room for customized division rules or replacement words, others may be performing the calculation in a creative way or an interesting language.

This repository serves as a collection of creative, interesting, unhinged, or even the occasional normal fizzbuzz implementation.

## Contribution rules
1. The program has to return an incremental count of numbers as an output and replace numbers according to the division rules listed above.
2. As long as the output plays fizzbuzz correctly you're fair game. The way that the output is calculated or displayed is up to you!
3. No API keys, no secrets. If an external web API or any calls to an external service are used, for whatever wacky reason, please ensure that it can be used for free without the need for a key, and ensure safety and compliance to TOS. 
4. Absolutely no malicious or unsafe code. Goes without saying.
5. No AI. Please don't submit LLM generated code. Using machine learning methods within your submissions is fine, but please also keep rule 3 in mind.
6. Kep your changes isolated to your own subdirectory.
7. Include instructions for running your program in a `README.md` file of your program. For formatting, see the example implementation `vanilla`.
8. Go wild. Be creative.
