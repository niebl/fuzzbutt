# FuzzButt
A collection of FizzBuzz implementations

## What is FizzBuzz?
According to [wikipedia](https://en.wikipedia.org/wiki/Fizz_buzz) Fizz Buzz is a word game in which Numbers are counted up incrementally, but replaced with the words "Fizz", "Buzz", or "Fizzbuzz" if the number meets the following division rules:
1. Any number divisible by 3 is replaced with "fizz"
2. Any number divisible by 5 is replaced with "buzz"
3. Any number divisible by both is replaced with "fizzbuzz"

This word game is often used as a programming exercise in classrooms or interviews. Some implementations may leave room for customized division rules or replacement words, others may be performing the calculation in a creative way or an interesting language.

This repository serves as a collection of creative, interesting, unhinged, or even mundane fizzbuzz implementation.

## Some Contribution rules
1. The program has to return an incremental count of numbers as an output and replace numbers according to the division rules listed above.
2. As long as the output plays fizzbuzz correctly you're fair game. The way that the output is calculated or displayed is up to you!
3. No API keys, no secrets. The program has to work out of the box without modifications to code
4. If an external web API or any calls to an external service are used, for whatever wacky reason, please ensure that it can be used for free without the need for a key, and ensure safety and compliance to TOS. 
5. Absolutely no malicious or unsafe code. Goes without saying.
6. No AI &mdash; Don't contribute LLM generated code. Fizzbuzz is a brainteaser, you wouldn't let a chatbot solve your crossword puzzle.
7. Using machine learning methods to perform fizzbuzz in a creative way is fine, but always keep the other rules in mind.
8. Keep your changes isolated to your own subdirectory.
9. Include instructions for running your program in a `README.md` file of your program. For formatting, see the example implementation [vanilla](vanilla/README.md). Requires all paragraphs in `vanilla` example in the same order.
10. Go wild. Be creative.
